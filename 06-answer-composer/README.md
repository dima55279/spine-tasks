# Answer Composer

Проверка ответа и ссылок на источники для задания 06 направления
«Инфраструктура базы знаний и агента вопросов и ответов».

## Установка

`uv` должен быть установлен как глобальный инструмент рабочего окружения.

```bash
uv sync --dev
```

Необязательный слой OpenAI-compatible composer устанавливается отдельно:

```bash
uv sync --extra llm --dev
```

## Правило валидации

`validate_answer()` является чистой функцией и не вызывает LLM. Ответ получает
статус `answered` только если каждое утверждение:

- содержит хотя бы одну citation;
- ссылается только на доступные chunk id;
- использует новейшую доступную редакцию источника;
- подтверждается текстом цитируемого фрагмента.

При частичном покрытии реализация возвращает `abstained`, а не показывает
усечённый ответ. Это консервативное правило: ни один `answered` не содержит
неподтверждённых утверждений.
