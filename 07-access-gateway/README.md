# Access Gateway

Шлюз доступа к знаниям для задания 07 направления «Инфраструктура базы знаний и
агента вопросов и ответов».

## Установка

`uv` должен быть установлен как глобальный инструмент рабочего окружения.

```bash
uv sync --dev
```

## Смысл

`AuthorizedRetriever` оборачивает любую реализацию `Retriever`, сам формирует
`RetrievalQuery` из `Subject` и повторно проверяет каждый возвращённый фрагмент.
Правило по умолчанию — запретить доступ. Доступ разрешён только если совпадает
workspace и у пользователя есть требуемая группа.

При отказе создаётся audit-событие с идентификаторами, причиной и версией политики,
но без текста закрытого фрагмента.
